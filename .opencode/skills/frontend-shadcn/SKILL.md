# frontend-shadcn

Use only:
- shadcn/ui
- Tailwind CSS
- Radix primitives through shadcn/ui
- lucide-react icons
- shadcn CSS variables

No other UI library.

Style direction:
- minimal
- monochrome
- white canvas
- thin borders
- compact panels
- table-like metric rows
- no heavy shadows
- no gradients
- no glassmorphism
- no colorful admin dashboard look

Prefer:
- border
- divide-y
- rounded-md
- shadow-none
- text-sm
- text-xs
- tabular-nums
- bg-background
- text-foreground
- text-muted-foreground
